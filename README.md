# Daily, To-Do List Dashboard

Dashboard harian sederhana dengan sapaan personal, timer fokus, daftar tugas,
dan tautan cepat. Semua data disimpan di browser menggunakan Local Storage.

## Menjalankan

Buka `index.html` di browser modern. Tidak perlu instalasi, server, atau backend.

## Fitur

- Sapaan menyesuaikan waktu dan nama yang disimpan.
- Timer fokus dengan pilihan durasi, mulai, jeda, dan reset.
- Tambah, selesaikan, filter, dan hapus tugas.
- Tautan cepat ke Google Calendar, Gmail, Drive, dan Notion.

Data tugas, nama, dan status timer tersimpan lokal di browser yang digunakan.
